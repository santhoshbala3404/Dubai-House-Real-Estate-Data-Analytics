# Dubai Real Estate Data Analytics

## Project Overview

This project focuses on exploring housing price data to understand the factors associated with property values in Dubai.

The analysis examines property characteristics such as square footage, number of bedrooms, number of bathrooms, neighborhood type, and year built.

Using Power BI, the project aims to explore relationships between property features and housing prices and present the findings through visual analysis.

## Tools & Technologies
- **Microsoft Power BI:** Data visualization and dashboard development.
- **CSV:** Dataset storage and analysis.

## Key Areas of Analysis
- Average property prices across neighborhood types.
- Relationship between square footage and property prices.
- Average prices based on bedroom count.
- Average prices based on bathroom count.
- Property pricing trends based on year built.
- Comparison of property characteristics and market segments.

## Dataset Description

The dataset contains the following attributes:
- SquareFeet
- Bedrooms
- Bathrooms
- Neighborhood
- YearBuilt
- Price

## Project Files
- `housing_price_dataset.csv` – Housing price dataset.
- `dubai_house_price_analysis.pbix` – Power BI dashboard.
- `Dubai_House_Price_Analysis_Report.pdf` – Analysis report.

## Project Objective

To understand how property characteristics and neighborhood classifications relate to housing prices and provide a structured view of real estate data for buyers, investors, and other stakeholders.

## Conclusion

This project demonstrates the use of Power BI to explore real estate datasets and present property pricing patterns through interactive visual analysis.

The findings should be interpreted as exploratory observations rather than verified market forecasts.
